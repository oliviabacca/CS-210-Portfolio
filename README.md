# CS-210-Portfolio
For module 8 of my CS 210 class I have chosen one of my projects to upload to my Github portfolio. I chose to upload project 2 because it reflects my current understanding and potential growth of C++ more accurately.

I chose Project 2 because out of the three projects we completed in this class it was the one I was most comfortable doing. The project is an investment calculator that takes an initial investment, monthly deposit, annual interest rate, and number of years from the user. It then calculates and displays the projected investment growth with and without monthly deposits. The purpose of the program is to show how an investment can grow over time through monthly compounding and regular contributions.

I think I did particularly well with separating the programs functionality into different functions. This helped keep the code organized and made each function responsible for a specific task. Separating the input validation and investment calculations made the program easier to understand and manage.

One area where I could enhance my code is the efficiency of the investment calculations. The program currently uses loops to calculate the balance and interest of each month and year. While this works well for the size of the calculations required by the project, I could explore ways to make the calculations more efficient for larger or more complex investment projections. This could help the program perform better while still producing accurate results.

One of the most challenging parts of this project was understanding how the different files worked together. Learning how main.cpp, Investment.h, and Investment.cpp, each had a different purpose was a learning experience throughout the term. I had to learn how information and functionality could be separated between files while still allowing the program to work together as a whole. This is something I have found myself exploring in other programming languages as well, so developing this understanding in C++ has been useful beyond this particular project. I used the course materials, examples, debugging, and practice to better understand how the different parts of a program connect. 

One of the most transferable skills I gained from this project is understanding how different files and classes can work together within a program. This is useful because different programming languages and projects can organize code in different ways, but the idea of separating and connecting different parts of a program is common across programming. Understanding this concept will help me work with larger and more complex projects in future courses and programming languages.

I made the program more maintainable and readable by separating different parts of the program into separate files and functions. The main.cpp file handles the main program and user interaction, while investment.h defines the Investment class and Investment.cpp contains the investment calculations. I also used separate functions for specific tasks instead of putting all of the program's functionality in one place. This organization makes the code easier to follow and makes it easier to modify or add functionality in the future.
